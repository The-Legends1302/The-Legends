# The-Legends
THE LEGENDS es un universo creativo de historias originales de superhéroes, ciencia ficción, aventura, misterio y fantasía. Creamos personajes, cuentos, mundos y videojuegos con historias conectadas y experiencias únicas. Descubrí nuevos héroes, enfrentá grandes amenazas y sé parte de un universo donde cada historia puede convertirse en una leyenda
